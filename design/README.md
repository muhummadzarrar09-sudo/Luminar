# Design

Exploration images for the Recto logo, kept for reference.

- `concept_a_monogram.png` - the chosen direction: an R whose counter is a
  page with a dog-eared corner. Shipped as a hand-written vector at
  `app/src/main/res/drawable/ic_launcher_foreground.xml`, not as this raster.
- `concept_b_negative.png` - rejected: open book cut out of a rounded square,
  right page curling into an R. Reads well large, muddy at icon size.

These are ~800 KB each. They are exploration artefacts, not build inputs -
nothing in the app references them. Safe to delete if the repo gets heavy.
